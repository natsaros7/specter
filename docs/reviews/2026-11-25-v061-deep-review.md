## Checked and found sound

- **`small()` numstat parsing.** `-z` with `--no-renames`: a path with a tab and a newline (`tests/t<TAB>ab<LF>nl_test.py`)
  losing a line gives `tests changed, not only added: tests/t<TAB>ab…`; `split("\t", 2)` keeps the tab in the path. A
  rename of a test file counts as a deletion of the old path (`tests changed: tests/x_test.py`). A test file turned into
  a symlink is numstat `1 2` (`tests changed`). A `.gitattributes` marking tests `-diff` turns them into `-  -`, binary,
  over the cap (and `.gitattributes` itself is the last row). Staged mode diffs the index against the same base
  (`size 4 files / 4 lines > cap 3/50` with four staged docs files). An empty diff never reaches `small()`
  (`classify()` gives the last row). A malformed numstat entry raises inside `ready.py` (traceback, exit 1, so no
  auto-merge) and is caught as a refusal (exit 2) in the label.
- **Size cap and Tests read at the base.** `small()` reads `profile_at(root, base, rel)`; a bad Evidence cell is
  `size: <msg>` (spot) in `small()`, `evidence: …` (spot) in the label, exit 2 in `--evidence` with `file:line`. A PR
  that edits its own caps or `## Tests` edits the profile, a guarded path (last row). `mf`, `ml` default to 3/50 for a
  placeholder row, a 6-column table or `-`.
- **Every v061 condition only takes `none` away.** In the label, `small()` runs only while `human == "none"` and
  after `earned()`; in `ready.py`, `earned()`, the family, `complexity` and `small()` are joined into `human_why`, and
  any one gives `spot`. `--auto-merge` without `--range` is `auto-merge: no (needs --range base...head)`.
- **`complexity:` parsing.** Only the visible `### Review` block is read; `- complexity: trivial (…)`,
  `- complexity : trivial` and a second line are not ready; `* complexity:` and an indented line read as missing (spot).
- **Task 8 cannot make a tier eligible.** Dropping a `0` only removes zeros from the human-caught denominator, so the
  rate can only go up (finding 4 is the over-strict side). The hold skip needs the tier's row at the evidence profile to
  say `none`; Min merged still needs `max(low, 1)` merges, and reverts and escapes are still counted.
- **Task 4 key.** A row whose globs change, or a renamed row, starts over (13c rows 946-950 pass). Human and Reviewer
  are not compared, so a promotion keeps its evidence (decision 7).
- **Task 5 window extension.** A named commit below the cut joins alone; a joined commit is always named by a later
  entry, so it counts as reverted or escaped, never as clean dilution. A NUL in a crafted commit body
  (`hash-object --literally`) is truncated by `git log %B`, so `-z` records stay aligned.
- **Refs.** `branch_ref` lists every ref once and refuses a hit or a symref target with a case-fold twin, a target not
  listed, a symref to another `…/HEAD` ref, a tag, an ambiguous name. `merged_ref` returns the fallback's `why`.
  `end_commit` takes a 40/64-hex end only when `rev-parse` returns it unchanged. A non-UTF-8 ref name in
  `packed-refs` fails closed everywhere (label refuses, `auto-merge: no`, `--evidence` exit 2), though the message
  blames `spec-kit.json` ("cannot read .specs/spec-kit.json at HEAD: 'utf-8' codec …"), because `branch_ref`'s
  `UnicodeDecodeError` is caught by `committed_ref()`.
- **UTF-8.** `profile_at()` raises `not UTF-8`; `ready.py` catches it at both reads; `--check` reads with
  `encoding="utf-8"`.
- **`GIT_NO_REPLACE_OBJECTS`.** Set once at `tiers` import, before any git call; `ready.py` imports `tiers` first, so
  its own git calls inherit it (task 7 row `t13e14` passes).
- **`gates.sh --docker`.** An empty mount exits 2; a failed image pull or OOM kill is a non-zero `docker run`; the
  exit code is the first non-zero gate's.
- **Recipe, GitHub.** `pull_request_target` from the default branch, an environment that only the default branch can
  deploy to, `commit_id` plus `--match-head-commit` plus a re-read, `concurrency` without cancel, and
  `persist-credentials: false` for PR-code workflows are consistent with decisions 2 and 4. Not run live (see below).
